# Generative_Closures_Geometry

This repo provides runnable demos for autoencoders (AE) and latent generative models, along with the test data and pretrained weights needed to reproduce the showcased performance in the submitted paper "Synergizing Transport-Based Generative Models and Latent Geometry for Stochastic Closure Modeling".

## Repo structure

- `Data/`  
  Testing data used by the demo scripts.

- `Models/`  
  Model architectures and training scripts (AE + latent generative models).

- `Trained_Models/`  
  Pretrained weights/checkpoints for the autoencoders and latent generative models.

- `Demos/`  
  Runnable scripts that demonstrate reconstruction and generation performance.

- `utils.py`  
  Shared helper functions used across training and demos.
